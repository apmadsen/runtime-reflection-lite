# Constructor : [Method](method.md)

The `Constructor` class represents a class constructor function. As of version 0.2 this can be either the `__new__` or the `__init__` function depending on which one is more applicable for class instantiation.

If a class or one of its bases defines a `__new__`function, this will be the one taken into account.
