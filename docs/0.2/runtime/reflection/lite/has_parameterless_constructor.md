# has_parameterless_constructor(cls: _type[Any]_) -> _bool_

The `has_parameterless_constructor` function checks if type has a parameterless constructor, ie. it can be instantiated without supplying any parameters.

## Parameters

- cls `type[Any]`: The class of which the constructor is reflected.
